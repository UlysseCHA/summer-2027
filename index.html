    Mon suivi de candidatures

    Stocke dans ton navigateur (localStorage), separement pour chaque compte. Rien n'est envoye nulle part. Utilise l'export si tu changes de machine.

    Mon profil

    Ces informations remplissent les formulaires de candidature via npm run apply. Elles sont ecrites dans data/profile.json, sur ta machine uniquement : ce fichier est ignore par git et ne part jamais sur le depot public.

    Cette page est ouverte depuis le site en ligne, qui ne peut pas ecrire sur ton disque. Lance npm start et ouvre http://localhost:5173 pour enregistrer, ou remplis le formulaire ici et telecharge le fichier a placer dans data/.

    D'ou viennent ces offres ?

    Les annonces sont collectees depuis les API publiques des ATS (Greenhouse, Lever, Ashby) des 0 entreprises listees dans data/sources.json. Chaque offre pointe vers l'annonce officielle : il n'y a pas de copie de contenu, juste un index.

    A l'ouverture du site, la page reinterroge elle-meme tous ces boards en direct (les trois API autorisent les appels depuis un navigateur). Les offres apparues depuis ta derniere visite sont signalees, et celles qui ont ete fermees disparaissent.

    Ce que l'app ne peut pas faire

    • Elle n'est pas exhaustive. Aucune source ne contient « toutes » les offres. Les entreprises sous Workday, SmartRecruiters ferme ou portail maison (Goldman Sachs, McKinsey, Google, Jane Street...) n'exposent rien de public : elles sont regroupees dans l'onglet Portails entreprises.
    • Les dates limites ne sont pas fiables a extraire. Elles sont rarement structurees dans les annonces. Un badge signale les offres dont la description mentionne une deadline.
    • L'annee du programme est parfois deduite. Beaucoup d'annonces ne disent jamais « 2027 ». Si l'annonce a ete publiee pendant la fenetre de recrutement Summer 2027, elle est rattachee a cette campagne et marquee annee deduite.
    • La connexion n'est pas une securite. Le site est statique : la verification se fait dans le navigateur et se contourne en ouvrant les outils de developpement. Elle sert a separer les profils, pas a proteger quoi que ce soit.

    Rafraichir en profondeur

    Le rafraichissement du navigateur ne lit que les titres. Pour recharger aussi les descriptions (meilleure detection de l'annee), depuis le dossier du projet : 

    npm run fetch        # recollecte complete
npm run discover     # cherche de nouveaux job boards
npm run check-links  # verifie les liens des portails
